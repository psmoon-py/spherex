# Use of AI in this project

Six Months Apart was developed and tested by me. I directed the project, developed and integrated its components, worked with the astronomical data, and evaluated whether the application functioned correctly.

AI tools were used as development assistants, primarily for debugging, troubleshooting, and resolving technical issues. They also provided some code snippets and implementation suggestions that I incorporated or adapted where appropriate.

AI did not independently build, test, or validate the completed application.

## Tools used

| Tool | How it was used |
|---|---|
| Anthropic Claude | Limited code snippets and implementation suggestions; primarily debugging and troubleshooting assistance |
| OpenAI ChatGPT | Numerical calculation cross-checks and technical guidance |

## Testing and validation

**All application testing and validation were performed by me, without AI tools carrying out the tests.**

My testing and verification included:

- Running unit tests and checking their results against expected values.
- Testing the application with real SPHEREx archive observations.
- Comparing astronomical results with NASA JPL Horizons and Gaia DR3.
- Manually examining the preset targets and checking whether the application worked as intended.
- Investigating errors and confirming whether corrections resolved them.

AI-generated explanations or numerical cross-checks were advisory. They were not substitutes for my own testing or independent scientific validation.

## Data and media

The project uses real NASA SPHEREx observations.

No AI-generated images, videos, or audio were used.

## Responsibility

I directed the development, integrated the implementation, carried out the testing and validation, reviewed the final results, and take responsibility for the submitted project and its limitations.
